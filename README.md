# Executive_Dashboard_Report
An interactive executive dashboard providing key business insights, performance metrics, and data-driven visualizations to support strategic decision-making.

## Project Overview
This Tableau dashboard analyzes global video game sales by genre and region. It helps executives see which genres earn the most and how sales differ between markets.

## What the Dashboard Shows
Global sales by genre
European sales by genre
Comparison of global and European sales
Global sales trends by year and genre
Japan and North America sales compared

## Tools Used
Tableau Public Desktop

## Key Insights
Action and Sports lead in global sales.
Sales rose steadily to a peak around 2005 to 2010, then declined.
Regional sales patterns differ from the global picture.

## How to View
Download the Tableau workbook (.twb) or the zip file from this repository and open it in Tableau.
